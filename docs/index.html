ggtag editor help

Select a command row, then click or drag on the canvas to reposition it (X, Y update live).

Keyboard: Ctrl+Z undo, Ctrl+Y / Ctrl+Shift+Z redo.
Drop a PNG file onto the page to add it as an image command.

Command parameters:
Text: X, Y, size (1–5), text
Rect / FillRect: X, Y, width, height
Circle / FillCircle: X, Y, radius
Line: X1, Y1, X2, Y2
QR code: X, Y, point-width, text
Image: X, Y, W, H, dither, URL
Icon: X, Y, height, FA name
RFID: mode (em/hid), ID, UID
